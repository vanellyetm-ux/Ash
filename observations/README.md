# Artifact Observation Network

This directory records artifacts for future observation, comparison, provenance analysis, and historical continuity. It is additive and non-destructive.

- Source artifacts remain unchanged; observations are appended.
- Preserve original source bytes and locators. Hash exact bytes without normalization.
- A fingerprint proves content identity only, not authorship, consent, approval, or authority.
- Attribute user-authored, assistant-generated, imported, and generated artifacts separately.
- Unknown values remain unknown; conflicts are preserved.
- Read-only by default. This folder grants no repository write access or execution authority.
- Consequential actions require independently verifiable authorization bound to exact scope and content.
