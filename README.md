# Ash

Ash is the structured knowledge and stewardship destination in the OLPIRT → GHOST → $ilk integration.

## Integration status

- This work is proposed on `integration/ghost-olpirt-knowledge-hq`.
- AshShow is a separate downstream presentation destination. No write access to the AshShow organization is assumed or required for this repository PR.
- Imported material must retain source lineage, classification, confidence, and review state.
- Publication and promotion remain human-approved actions.

## Promotion states

`DRAFT` → `SOURCE_VERIFIED` → `EVIDENCE_REVIEWED` → `IMPLEMENTATION_VERIFIED` → `PROMOTION_APPROVED` → `PUBLISHED`

A transfer receipt is not publication. A successful write is not evidence approval. No automated process may promote an item to `PUBLISHED` without an explicit human approval record.
